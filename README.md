# Microcontrollers-and-Embedded-Electronics-Labs

## Introduction

This repository contains the laboratory experiments completed for the **BECS 31421 Microcontrollers and Embedded Electronics** module at the **University of Kelaniya**.

It brings together PIC16F628A-based embedded systems work, including MikroC PRO programs, Proteus simulations, HEX files, circuit-related materials, and supporting lab documentation in one place for easy reference and reuse.

## Module Information

- **Module Code:** BECS 31421
- **Module Name:** Microcontrollers and Embedded Electronics
- **Institution:** University of Kelaniya
- **Focus Areas:** PIC microcontroller programming, interfacing, simulation, and embedded systems applications

## Software Used

- **MikroC PRO** - for writing and compiling PIC microcontroller programs
- **Proteus** - for circuit design and simulation
- **MPLAB IPE** - for programming and device management
- **PicKit 3 Programmer** - for loading compiled programs into the microcontroller

## Hardware Used

- **PIC16F628A microcontroller**
- **PicKit 3 programmer**
- **16×2 LCD display**
- **LEDs and basic input/output components**
- **7-segment display**
- **DC motor**
- **Relay**
- **Push buttons, buzzer, and other supporting lab components**

## Laboratory Experiments

1. **Lab 01:** Introduction to Software Tools: MikroC, Proteus, and PicKit 3 Programmer
2. **Lab 02:** Introduction to Input and Output in PIC Programming
3. **Lab 03:** Microcontroller-Implemented LED Chaser
4. **Lab 04:** Interrupt Handling with a PIC Microcontroller
5. **Lab 05:** Interfacing a 16×2 LCD with a PIC Microcontroller
6. **Lab 06:** Interfacing DC Motor with PIC Microcontroller
7. **Lab 07:** Implementing a PIC Microcontroller-Based Quiz Buzzer
8. **Lab 08:** Pulse Width Modulation (PWM) with Microcontroller
9. **Lab 09:** Interfacing 7-Segment Display
10. **Lab 10:** Implementing Relay Control with PIC Microcontroller
11. **Lab 11:** Microcontroller-Based Simple Calculator

## How to Use This Repository

1. Open the folder for the relevant lab experiment.
2. Review the source code and related documentation.
3. Use **Proteus** to inspect or run simulation files where available.
4. Use **MikroC PRO** to build or modify the embedded C programs.
5. Use **MPLAB IPE** and **PicKit 3** to program the PIC16F628A when working with hardware.

This repository is useful for revision, practical reference, and organizing embedded systems laboratory work in a clear and consistent manner.
